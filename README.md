# CleanCity – archivos fuente

Copia la carpeta `src/` encima de la `src/` de tu proyecto Ionic (acepta reemplazar)
y borra `src/app/home/home.page.html` y `src/app/home/home.page.scss`.
Pega `firestore.rules` en Firebase Console > Firestore > Reglas y publica.
Edita `src/environments/environment.ts` con tu configuración de Firebase.
